# TCP转发服务器 - 功能总结

## ✅ 已实现的所有功能

### 🎯 核心需求（完全满足）

1. **✅ TCP协议端口转发**
   - 支持TCP请求转发到后端HTTP服务器
   - 高性能的连接处理和数据转发

2. **✅ 多端口映射配置**
   - 支持同时配置多个端口映射规则
   - 例如：80->ip1:3000, 81->ip2:3001
   - 每个映射独立运行，互不影响

3. **✅ 配置文件管理**
   - 通过config.json文件进行配置
   - 支持动态加载和保存配置

4. **✅ Node.js开发**
   - 完全基于Node.js原生模块开发
   - 无外部系统依赖

### 🚀 增强功能（超出需求）

#### WebUI管理界面
- **✅ 用户认证系统**
  - 安全的登录/登出功能
  - 密码加密存储（bcrypt）
  - 登录失败次数限制（5次后锁定30分钟）
  - IP地址跟踪和审计日志

- **✅ 可视化管理面板**
  - 现代化的Web界面设计
  - 中英文界面切换，语言偏好本地保存
  - 深色 / 浅色主题，自动跟随系统并记住选择
  - 响应式布局，支持移动设备
  - 实时状态展示

- **✅ 动态配置管理**
  - 无需重启即可添加/删除端口映射
  - 实时配置保存和加载
  - 输入验证和错误处理

#### 连接状态监控
- **✅ 实时连接监控**
  - 显示每个端口的连接数量
  - 显示客户端源地址、实际监听地址和目标地址
  - 显示数据传输量（上行/下行）
  - 显示连接持续时长与状态
  - 保留最近 500 条已关闭连接记录，可按映射筛选
  - 关闭日志包含持续时长、流量与关闭原因

- **✅ 系统状态展示**
  - 总映射数量
  - 活跃映射数量
  - 总连接数
  - 系统运行时间
  - 内存使用情况

#### 安全机制
- **✅ 密码安全策略**
  - 密码复杂度要求（8字符+大小写+数字）
  - 密码过期机制（90天）
  - 安全的密码哈希存储

- **✅ 访问控制**
  - 会话管理（24小时超时）
  - 登录尝试限制
  - 用户账户启用/禁用

- **✅ 审计日志**
  - 登录成功/失败记录
  - 操作日志记录
  - IP地址跟踪

#### 运维功能
- **✅ 日志级别控制**
  - 支持error、warn、info、debug级别
  - 日志级别过滤功能
  - 时间戳和结构化日志

- **✅ 优雅关闭**
  - 支持Ctrl+C安全退出
  - 自动清理连接资源
  - 多服务器实例管理

## 🛠 技术栈

### 后端技术
- **Node.js** - 运行时环境
- **原生 net 模块** - TCP 转发与背压控制
- **Express.js** - Web框架
- **bcryptjs** - 密码加密
- **express-session** - 会话管理

### 前端技术
- **原生HTML/CSS/JavaScript** - 无框架依赖
- **现代CSS** - Flexbox/Grid布局
- **Fetch API** - 异步请求
- **响应式设计** - 支持多设备

### 安全技术
- **bcrypt密码哈希** - 可配置加密强度
- **会话加固** - 登录后重建 Session ID、HttpOnly + SameSite Cookie
- **CSRF防护** - 校验写请求的 Origin 来源
- **输入验证** - 端口、主机名、映射名称校验
- **XSS防护** - 前端统一转义动态内容
- **安全响应头** - CSP、X-Frame-Options、nosniff

## 🚀 部署方式

### 快速部署
```bash
# 自动部署（推荐）
./deploy.sh

# 手动部署
npm install
npm run setup-password
npm start
```

### 生产环境
```bash
# 设置环境变量
export NODE_ENV=production
export SESSION_SECRET=$(openssl rand -base64 32)

# 设置文件权限
chmod 600 auth-config.json

# 启动服务
npm start
```

## 📊 性能特点

- **高并发**：支持大量同时连接
- **低延迟**：TCP_NODELAY + 直接转发，无额外处理
- **背压控制**：慢速对端不会导致内存无限增长
- **半关闭支持**：兼容使用 TCP half-close 的协议
- **资源优化**：连接关闭、映射停止和进程退出时自动清理
- **稳定性**：错误隔离，单个映射故障不影响其他服务
