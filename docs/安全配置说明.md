# TCP转发服务器 - 安全配置说明

## 🔐 密码安全配置

### 1. 初始密码设置

**⚠️ 重要：首次使用前必须设置安全密码**

```bash
# 运行密码设置工具
npm run setup-password

# 或直接运行
node setup-password.js
```

### 2. 密码策略要求

默认策略如下（可在 `~/.tcpmapping/auth-config.json` 的 `passwordPolicy` 中调整）：

- ✅ 最少8个字符
- ✅ 包含大写字母 (A-Z)
- ✅ 包含小写字母 (a-z)
- ✅ 包含数字 (0-9)
- ✅ 密码有效期90天

> ⚠️ 系统没有默认密码。未运行 `setup-password` 时，WebUI 管理界面不会启动。

### 3. 安全功能

#### 登录保护
- 🔒 **失败次数限制**：5次失败后账户锁定30分钟
- 📍 **IP地址跟踪**：记录登录尝试的IP地址
- 📝 **审计日志**：记录所有登录活动

#### 会话管理
- ⏰ **会话超时**：默认24小时后自动退出（可通过 `sessionConfig.sessionTimeout` 调整）
- 🔄 **会话重建**：登录成功后重新生成 Session ID，防止会话固定攻击
- 🍪 **Cookie 加固**：`HttpOnly` + `SameSite=Lax`
- 🔄 **密码过期**：90天后强制修改密码
- 🚫 **账户禁用**：支持禁用特定用户

### 4. 环境变量配置 (可选)

```bash
# 覆盖数据目录（默认 ~/.tcpmapping）
export TCPMAPPING_DATA_DIR=/var/lib/tcpmapping

# 覆盖 WebUI 监听地址和端口
export WEBUI_HOST=127.0.0.1
export WEBUI_PORT=9999

# 覆盖会话签名密钥（建议使用足够长的随机字符串）
export SESSION_SECRET="$(openssl rand -hex 32)"
```

### 5. 生产环境部署建议

#### 基本安全措施
1. **使用HTTPS**：在生产环境中始终使用SSL/TLS
2. **防火墙配置**：限制Web管理端口的访问
3. **定期更新密码**：建议每30-60天更新一次
4. **备份配置**：定期备份`auth-config.json`文件

#### 高级安全配置
```bash
# 生产环境下限制管理面板只允许本机访问
# config.json: "webui": { "host": "127.0.0.1", "port": 9999 }

# 通过反向代理提供 HTTPS，并限制来源 IP
# 同时建议设置 NODE_ENV=production
export NODE_ENV=production
```

### 6. 文件权限设置

```bash
# 设置认证配置文件的安全权限（CLI 设置密码时会自动设置为 600）
chmod 600 ~/.tcpmapping/auth-config.json
chmod 600 ~/.tcpmapping/.session-secret
```

### 7. 密码重置

如果忘记密码，可以重新运行设置工具：

```bash
npm run reset-password
```

### 8. 安全检查清单

部署前请确认：

- [ ] 已运行`npm run setup-password`设置强密码（系统无默认密码）
- [ ] `auth-config.json`文件不在版本控制中
- [ ] `webui.host`未暴露到公网，或已通过防火墙限制来源
- [ ] 生产环境使用HTTPS
- [ ] 防火墙已正确配置
- [ ] 定期备份配置文件
- [ ] 监控登录日志

### 9. 故障排除

#### 常见问题

**Q: 忘记密码怎么办？**
A: 运行`npm run reset-password`重新设置密码

**Q: 账户被锁定怎么办？**
A: 等待30分钟后重试，或重启服务器清除锁定状态

**Q: 密码过期提示怎么办？**
A: 运行`npm run setup-password`更新密码

#### 紧急访问

系统没有后门密码，也无法通过删除配置文件获得默认密码。如果无法登录：

1. 在服务器上运行 `tcpmapping setup-password` 重置管理员密码
2. 如因多次失败被锁定，重启服务（`tcpmapping restart`）会清除锁定状态
3. 重置后立即使用新密码登录

### 10. 日志监控

系统会记录以下安全事件：

- 登录成功/失败
- 账户锁定
- 密码修改
- 转发服务器启停与连接错误

查看日志：
```bash
# 查看最近的安全事件
tcpmapping logs

# 实时跟踪
tcpmapping logs -f

# 日志文件位置（默认）
# ~/.tcpmapping/tcpmapping.log
```
