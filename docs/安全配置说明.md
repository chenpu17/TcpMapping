# TCP转发服务器 - 安全配置说明

## 🔐 密码安全配置

### 1. 初始密码设置

**⚠️ 重要：首次使用前必须设置安全密码**

```bash
# 运行密码设置工具
npm run setup-password

# 或直接运行
node setup-password.js
```

### 2. 密码策略要求

系统强制执行以下密码策略：

- ✅ 最少8个字符
- ✅ 包含大写字母 (A-Z)
- ✅ 包含小写字母 (a-z)
- ✅ 包含数字 (0-9)
- ✅ 密码有效期90天

### 3. 安全功能

#### 登录保护
- 🔒 **失败次数限制**：5次失败后账户锁定30分钟
- 📍 **IP地址跟踪**：记录登录尝试的IP地址
- 📝 **审计日志**：记录所有登录活动

#### 会话管理
- ⏰ **会话超时**：24小时后自动退出
- 🔄 **密码过期**：90天后强制修改密码
- 🚫 **账户禁用**：支持禁用特定用户

### 4. 环境变量配置 (可选)

为了更高的安全性，可以通过环境变量配置：

```bash
# 设置管理员密码 (可选)
export ADMIN_PASSWORD="YourSecurePassword123"

# 设置会话密钥 (可选)
export SESSION_SECRET="YourRandomSessionSecret"

# 设置WebUI端口 (可选)
export WEBUI_PORT=9999
```

### 5. 生产环境部署建议

#### 基本安全措施
1. **使用HTTPS**：在生产环境中始终使用SSL/TLS
2. **防火墙配置**：限制Web管理端口的访问
3. **定期更新密码**：建议每30-60天更新一次
4. **备份配置**：定期备份`auth-config.json`文件

#### 高级安全配置
```bash
# 使用环境变量存储敏感信息
export NODE_ENV=production
export SESSION_SECRET=$(openssl rand -base64 32)
export ADMIN_PASSWORD_HASH=$(node -e "console.log(require('bcryptjs').hashSync('YourPassword', 12))")
```

### 6. 文件权限设置

```bash
# 设置认证配置文件的安全权限
chmod 600 auth-config.json
chown root:root auth-config.json  # 仅root用户可读写
```

### 7. 密码重置

如果忘记密码，可以重新运行设置工具：

```bash
npm run reset-password
```

### 8. 安全检查清单

部署前请确认：

- [ ] 已运行`npm run setup-password`设置强密码
- [ ] `auth-config.json`文件不在版本控制中
- [ ] 生产环境使用HTTPS
- [ ] 防火墙已正确配置
- [ ] 定期备份配置文件
- [ ] 监控登录日志

### 9. 故障排除

#### 常见问题

**Q: 忘记密码怎么办？**
A: 运行`npm run reset-password`重新设置密码

**Q: 账户被锁定怎么办？**
A: 等待30分钟后重试，或重启服务器清除锁定状态

**Q: 密码过期提示怎么办？**
A: 运行`npm run setup-password`更新密码

#### 紧急访问

如果完全无法访问，可以：

1. 删除`auth-config.json`文件
2. 重启服务器（将使用默认密码admin/admin123）
3. 立即运行`npm run setup-password`设置新密码

### 10. 日志监控

系统会记录以下安全事件：

- 登录成功/失败
- 账户锁定
- 密码修改
- 会话超时

查看日志：
```bash
# 查看最近的安全事件
tail -f logs/security.log

# 或通过系统日志查看
grep "TCP转发服务器" /var/log/syslog
```
